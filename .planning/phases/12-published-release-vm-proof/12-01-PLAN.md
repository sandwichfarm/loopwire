# Phase 12 Plan: Published Release Proof

**Status:** In Progress
**Owner:** Codex
**Date:** 2026-07-03

## Goal

Make the release proof repeatable without fabricating an unpublished release.

## Scope

- Add `scripts/verify-published-release.sh`.
- Add `scripts/verify-release-readiness.sh`.
- Add `scripts/verify-vm-evidence.sh`.
- Add `scripts/verify-github-workflows.sh`.
- Add `scripts/collect-release-evidence.mjs`.
- Add `scripts/collect-vm-evidence.sh` for guest-side VM evidence capture.
- Add GitHub secret helper audit and dry-run modes.
- Add `scripts/verify-support-matrix.mjs` so docs support claims follow VM metadata and evidence.
- Wire it into package scripts and syntax validation.
- Document the published-release smoke command.
- Document the release readiness preflight.
- Document the GitHub workflow contract verifier.
- Document GitHub secret check and dry-run ceremony.
- Document the VM evidence bundle contract.
- Document the release evidence bundle collector.
- Document guest evidence collection and PNG screenshot verification.
- Document support-matrix evidence promotion rules.
- Validate local release, VM metadata, docs, scripts, and GSD state.

## Out of Scope Until Explicit Release Decision

- Creating a public GitHub Release.
- Generating or committing project signing keys.
- Pushing tags or publishing package templates.
- Claiming live VM evidence without a VM run.

## Validation

- `pnpm verify:scripts`.
- `pnpm verify:workflows`.
- `pnpm verify:release`.
- `pnpm verify:vm`.
- `pnpm verify:support-matrix`.
- Local collector flow smoke with generated PNG test image, not support-matrix evidence.
- `pnpm verify:docs`.
- GSD queries and diff hygiene.
