# Phase 19 Plan: Native Distribution Packages and Matching-Guest Proof

**Status:** In progress
**Owner:** Codex
**Issue:** https://github.com/sandwichfarm/loopwire/issues/10
**Date:** 2026-08-30

## Architecture Layers

- Packaging and platform integration: deb controls, RPM specs, desktop metadata, portable binary builder.
- Release delivery: native attachments staged from the canonical release tarball.
- Verification: deterministic builder tests and checksum-bound KVM guest evidence.
- Documentation: install channels, support matrix, packaging runbook, and unreleased notes.

## Work

1. Add target-specific Ubuntu/Debian control files and Fedora/openSUSE spec files.
2. Add deterministic deb/RPM builders which validate the canonical release manifest and safe archive shape.
3. Include GUI, background restore, provider tools, backend detector, desktop entry, and icon in every native package.
4. Build the Linux GUI on a Debian 12 glibc baseline for use across the target matrix.
5. Add an official-image manifest and a Docker-contained QEMU/KVM runner with loopback-only SSH.
6. Add matching-guest install, metadata, runtime, visible-window, and uninstall proof plus a strict host verifier.
7. Add local regression coverage for package reproducibility, metadata, duplicate checksums, proof schema, and package
   tampering.
8. Replace GUI-only Tauri deb/RPM release attachments with the repository-owned x86_64 native packages.
9. Record the exact four-guest results, update public docs, run the full workspace gate, and open the issue-linked PR.

## Acceptance Criteria

- All four target recipes and their repository-owned build commands are committed.
- Two identical builds of every recipe produce byte-identical packages.
- Official image checksums are verified before launch and recorded in proof.
- Ubuntu 24.04, Debian 13, Fedora 44, and openSUSE Tumbleweed each pass inside their own KVM guest.
- Each proof binds exact package checksum/version/architecture and commit, proves a visible GUI window, and proves clean
  uninstall.
- Local full validation and hosted PR checks pass.
- The PR is open against the current default branch and links issue #10.

## Out of Scope

- Publishing packages to distro repositories.
- Claiming a public tagged Loopwire release exists.
- aarch64 native distro packages without matching guest proof.
- Host audio mutation or backend support promotion based only on package-install guests.
