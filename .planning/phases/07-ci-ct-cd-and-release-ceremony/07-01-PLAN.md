# Phase 7 Plan: CI/CT/CD and Release Ceremony Hardening

**Status:** Complete
**Owner:** Codex
**Date:** 2026-07-03

## Goal

Harden the workflow layer so source validation, host diagnostics, docs deployment, and release publishing each have the
right gates and evidence.

## Scope

- Add CI concurrency, job timeouts, Tauri dependency install, and `cargo check`.
- Add continuous-test concurrency, job timeout, and uploaded redacted diagnostics artifact.
- Add docs deploy docs-contract checks, protected ref gating, `docs-production` environment, and secret-safe deploy
  skipping.
- Require versioned release notes in the release workflow.
- Add post-publish install smoke by downloading GitHub Release assets and installing from the published artifact set.
- Update release documentation and GSD state.

## Out of Scope

- Running workflows on GitHub.
- Creating a public release.
- Adding hosted nested VM execution.
- Adding new dependencies for workflow validation.

## Validation

- Live action tag lookup with `git ls-remote`.
- Workflow YAML parse.
- `pnpm check`
- `pnpm detect:audio`
- `cargo check --manifest-path apps/desktop/src-tauri/Cargo.toml`
- GSD state queries.
- Code graph reindex.
