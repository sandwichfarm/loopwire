# Summary 15.1 — Power-User Surfaces (SEED-002, SURF-01..03)

## What changed

- **Transfer (SURF-01):** Settings gained a Transfer section. Export renders the selected device's versioned JSON
  (`exportConfiguration`) into a readonly textarea and copies to the clipboard when available; Import parses pasted
  JSON via a new `deviceStore.importDevice(raw)` (typed result, inserts + selects, invalid payloads leave state
  untouched and toast). `deviceStore.exportDevice(deviceId)` added alongside. Import re-applies the selection
  (`reapplySelectedDevice`) so the host tracks the imported device.
- **Diagnostics (SURF-02):** a Diagnostics disclosure under Settings → Audio Backend lists every backend capability
  report (`runtimeService.capabilityReports`): availability badge, mixing scope, per-operation states, and diagnostic
  messages; empty-state caption for browser preview.
- **Host bindings (SURF-03):** SourceCard and MonitorCard Options gained a Host binding text field, and BusBlock
  gained an Options strip carrying the same field. Wired through `deviceStore.setHostBinding` (core
  `setEndpointDeviceName`; empty clears) with role-specific placeholders; successful edits call
  `reapplySelectedDevice()`.
