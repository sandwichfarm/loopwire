# Plan 14.1 Summary — Multichannel Bus Creation (SEED-004, BUS-01)

**One-liner:** The Output Channels ⊕ is now a PopupMenu offering Stereo Bus (default/first), Mono Bus, and Quad Bus — each appended instantly on pick — with channel-count-aware labels (`Channel N`, `Channels N & M`, `Channels N–M`) computed from the cumulative start channel, and 4ch pairs cable 1→1…4→4 with no geometry changes needed.

## What Changed

### Desktop (`apps/desktop`)

- `stores/deviceStore.ts`:
  - `nextBusLabel(outputs, channels = 2)` — labels by width: 1ch → `Channel N`, 2ch → `Channels N & M`, wider → `Channels N–M` (en dash). Start channel stays cumulative across mixed-width buses.
  - `addBus(deviceId, channels = 2)` — passes the picked channel count into `addOutputBusToConfiguration` (which already accepted `channels`); still no auto-routing of existing sources.
- `components/DeviceCanvas.svelte`:
  - Output Channels `ColumnHeader` switched from `addAction="instant"` to `addAction="menu"`; opens a `PopupMenu` (same pattern as the sources/monitors menus) with items Stereo Bus (first/default, 2 channels), Mono Bus (1), Quad Bus (4).
  - `pickBus(menuId)` maps the pick to a channel count and reuses the existing `addBus` flow: append, auto-select the new bus, re-run live apply.
  - `openMenu.kind` union extended with `"buses"`.
- `BusBlock` needed no change: channel rows and labels already derive from `startChannel` + `endpoint.channels`.
- `cables/geometry.ts` needed no change: `channelCablesFor` uses `min(channels)`; a 4ch source → 4ch bus route draws 4 cables.

### Docs

- `apps/docs/docs/guide/configurations.md`: the bus bullet now describes the ⊕ menu with Stereo/Mono/Quad choices and the label forms.
- `apps/docs/docs/release-notes/unreleased.md`: rebuilt-UI bullet updated ("buses are added from a small ⊕ menu") plus a new bullet documenting the mono/stereo/quad menu and the deliberate divergence from the reference's instant stereo-only add (one-click-then-pick).
- `scripts/verify-docs.sh`: four new phrase assertions locking both doc surfaces (menu wording + divergence note). No existing needle broke.

### Tests Added/Extended

- `stores/deviceStore.test.ts`: mono label (`Channel 1`, `Channel 3`), quad label (`Channels 1–4`, `Channels 3–6`), cumulative start channel across mixed-width buses (1ch + 4ch → next stereo starts at 6), `addBus` with mono/quad channel counts and labels, and appended-bus-last ordering (what the canvas auto-select relies on).
- `cables/geometry.test.ts`: 4ch source → 4ch bus route expands into exactly 4 cables mapping channel 1→1 … 4→4.
