# Phase 2 Supplemental Plan: Guarded pactl Stream Routing

**Status:** Complete
**Requirements:** BACKEND-01, BACKEND-03, CONFIG-01 support path

## Goal

Move selected application sink inputs into Loopwire virtual sinks through `pactl` while preserving dry-run safety and
rollback behavior.

## Tasks

- [x] Extend the `pactl` runtime adapter to accept input endpoints and routes.
- [x] Treat non-muted routes as stream move plans from input endpoint metadata to output virtual sinks.
- [x] Match currently present sink inputs using input endpoint id and label tokens against `pactl list sink-inputs`.
- [x] Move matching sink inputs with `pactl move-sink-input`.
- [x] Verify matching sink inputs are on the expected Loopwire sink.
- [x] Roll moved sink inputs back to their original sinks if a later move fails.
- [x] Keep dry-run mode safe and fake-runner tested.

## Acceptance Criteria

1. Tests prove matching sink inputs move to the Loopwire target sink.
2. Tests prove muted routes do not move streams.
3. Tests prove moved streams are restored if a later move fails.
4. Tests prove verification fails when a matching stream is on the wrong sink.
5. No live host mutation is required for validation.

- Add monitor routing.
