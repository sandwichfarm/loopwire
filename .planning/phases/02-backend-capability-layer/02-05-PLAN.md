# Phase 2 Supplemental Plan: Guarded pactl Monitor Loopbacks

**Status:** Complete
**Owner:** Codex
**Date:** 2026-07-03

## Goal

Add a guarded PulseAudio compatibility primitive for monitor routing without leaving dry-run mode by default.

## Scope

- Extend the audio-host runtime configuration with optional monitor endpoints.
- Create Loopwire-owned monitor null sinks for configured monitors.
- Link each Loopwire output monitor source to each monitor sink with `module-loopback`.
- Verify expected monitor loopback modules exist.
- Unload only Loopwire-owned null-sink and loopback modules for the selected configuration.
- Keep live host mutation out of validation.

## Out of Scope

- Binding monitors to physical hardware sinks.
- Native PipeWire graph links.
- True per-edge matrix mixing.
- Desktop consent UI for live apply mode.

## Validation

- Focused audio-host fake-runner tests.
- Audio-host typecheck.
- Line-length check for touched audio-host files.
- Full repo validation after docs/state updates.
