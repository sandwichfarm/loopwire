# Phase 2 Supplemental Plan: Guarded pactl Virtual Sink Runtime

**Status:** Complete
**Requirements:** BACKEND-01, BACKEND-03, CONFIG-01 support path

## Goal

Move beyond read-only detection with the first safe host mutation primitive: create, verify, unload, and roll back
Loopwire-owned virtual sinks through `pactl`, without mutating the host by default.

## Tasks

- [x] Add a `pactl` runtime adapter in `@loopwire/audio-host`.
- [x] Keep dry-run mode as the default.
- [x] Add explicit `mode: "apply"` for callers that opt into host mutation.
- [x] Create one `module-null-sink` per Loopwire output.
- [x] Verify expected Loopwire sink names from `pactl list short sinks`.
- [x] Unload only modules whose `sink_name` matches the target Loopwire configuration.
- [x] Roll back module IDs that loaded before a later apply failure.
- [x] Update capability reports so PulseAudio compatibility reports implemented virtual sink create/apply/verify/rollback
  while stream routing and gain/mute remain planned.

## Acceptance Criteria

1. Tests prove dry-run mode does not call the command runner.
2. Tests prove apply failure unloads already-created module IDs.
3. Tests prove verification fails when a configured sink is missing.
4. Tests prove rollback targets only matching Loopwire module names.
5. Docs do not claim full audio routing support.

## Remaining Work

- Wire the desktop runtime to the host adapter behind an explicit user action.
- Implement application stream routing into Loopwire sinks.
- Implement monitor routing and per-route gain/mute host apply.
