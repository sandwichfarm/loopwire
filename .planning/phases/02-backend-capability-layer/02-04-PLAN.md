# Phase 2 Supplemental Plan: Guarded pactl Sink-Input Controls

**Status:** Complete
**Owner:** Codex
**Date:** 2026-07-03

## Goal

Apply persisted route gain and mute to currently present matching PulseAudio sink inputs without widening the host
mutation boundary beyond the existing guarded `pactl` adapter.

## Scope

- Carry route `gain` and `muted` into sink-input route plans.
- Use `pactl set-sink-input-volume` and `pactl set-sink-input-mute` only for matched sink inputs.
- Verify matching streams are on the expected Loopwire sink and have expected volume/mute state.
- Restore original sink, volume, and mute if a later stream operation fails.
- Keep dry-run mode as the default.

## Out of Scope

- Live host mutation during validation.
- Monitor routing.
- True per-edge matrix mixing when one source is routed to multiple outputs.
- Desktop consent UI for apply mode.

## Validation

- Focused audio-host tests.
- Audio-host typecheck.
- Full repo validation after docs and state updates.
