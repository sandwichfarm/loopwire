# Phase 9 Plan: Guarded PipeWire Existing-Port Links

**Status:** Complete
**Owner:** Codex
**Date:** 2026-07-03

## Goal

Add a native PipeWire runtime adapter for existing graph ports without claiming native virtual device creation.

## Scope

- Add `createPipeWireGraphRuntimeAdapter` to `@loopwire/audio-host`.
- Use `pw-link -o`, `pw-link -i`, and `pw-link -l` to plan and verify existing port links.
- Link active routes with `pw-link <output-port> <input-port>`.
- Unlink configured routes with `pw-link -d <output-port> <input-port>`.
- Roll back links created before a later link failure.
- Reject non-unity route gain before any host command.
- Update backend capability detection and docs to reflect implemented PipeWire link routing.

## Out of Scope

- Native PipeWire virtual node creation.
- Native PipeWire monitor routing.
- Native PipeWire gain/mute controls.
- Desktop live apply wiring.
- Live host mutation during validation.

## Validation

- Audio-host fake-runner tests and typecheck.
- `pnpm detect:audio` capability report.
- Full repository validation after docs and state updates.
