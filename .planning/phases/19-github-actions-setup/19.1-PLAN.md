# Phase 19 Plan: Hardened GitHub Actions Setup

**Status:** In progress
**Owner:** Codex
**Issue:** https://github.com/sandwichfarm/loopwire/issues/5
**Date:** 2026-08-30

## Goal

Provide one cross-platform operator command that explains, prompts for, validates, and sets every Loopwire GitHub
Actions variable and secret without leaking or mutating entered data.

## Scope

1. Add a Node.js prompt-driven setup command for Windows, macOS, and Linux.
2. Store non-sensitive Bunny configuration as GitHub Actions variables and credentials/signing material as secrets.
3. Preserve exact UTF-8 input and exact private-key file bytes by sending every value to `gh` over stdin.
4. Validate all answers, repository access, secret size, file safety, and signing-key pair before the first write.
5. Require explicit confirmation, report partial-write state without values, and verify variable readback plus secret names.
6. Add a fake-`gh` adversarial harness covering whitespace, quotes, Unicode, shell metacharacters, prompt separation,
   multiline PEM bytes, missing trailing newline, log redaction, and failed writes.
7. Update workflows and operator docs while retaining temporary fallback to existing repository secrets.

## Constraints

- Never place sensitive values in argv, environment variables, logs, or generated project files.
- Never trim, quote-strip, normalize, append a newline to, or concatenate entered values.
- Reject invalid values instead of silently rewriting them.
- Do not read a GitHub secret back; verify only its registered name.
- Preserve the unrelated `.playwright-mcp` worktree file.

## Validation

- Focused exact-byte transport tests using a fake `gh` executable.
- Node syntax and cross-platform path tests.
- Threat-model review of prompt, child process, filesystem, mutation, and logging surfaces.
- Full `pnpm check` and hosted PR checks.

## Out of Scope

- Creating Bunny resources or release signing keys on the user's behalf.
- Reading existing GitHub secret values.
- Performing a production deployment or release.
