# Phase 5 Plan: User-Scoped Startup Helper

**Status:** Complete
**Requirements:** LINUX-02, LINUX-03, LINUX-04

## Goal

Provide a tested, reversible, user-scoped startup path without modifying system directories or pretending host audio
restore is complete.

## Tasks

- [x] Add `scripts/manage-autostart.sh` for XDG desktop autostart and future systemd user service rendering.
- [x] Keep desktop autostart as the current safe path for the GUI app.
- [x] Keep systemd mode explicit and forward-compatible with background restore.
- [x] Add `scripts/verify-autostart.sh` to validate rendered desktop and systemd files in a temporary directory.
- [x] Add package scripts for autostart status/install and verification.
- [x] Update install/start-on-boot/docs/VM evidence requirements.
- [x] Run validation gates.

## Acceptance Criteria

1. Users can preview startup entries before installing them.
2. Desktop autostart can be installed and uninstalled under user config paths only.
3. Systemd user unit shape can be rendered and dry-run enabled without touching the host.
4. Verification runs without requiring systemd or a real installed Loopwire binary.
5. Docs clearly separate the current GUI startup path from future background audio restore.

## Remaining Phase Work

- Wire startup helper into release installer after release assets contain the helper.
- Implement background restore mode in the packaged binary or daemon.
- Add AUR and Nix packaging smoke paths.
- Prove install from published release artifacts before claiming public install readiness.
