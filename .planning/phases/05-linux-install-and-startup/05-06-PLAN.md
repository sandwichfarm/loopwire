# Phase 5 Plan: Signed Release Manifest Verification

**Status:** Complete
**Requirements:** LINUX-03, QUAL-03, QUAL-05 support path

## Goal

Make release artifact integrity stronger than bare checksums by signing `SHA256SUMS` and requiring installer-side
signature verification.

## Tasks

- [x] Add a script to sign release manifests.
- [x] Add a script to verify release manifest signatures.
- [x] Make `scripts/stage-release-artifacts.sh` optionally sign staged release attachments.
- [x] Make `scripts/install.sh` require `SHA256SUMS.sig` and a trusted public key by default.
- [x] Keep unsigned installs behind an explicit `--skip-signature` flag for local development only.
- [x] Update installer and release smoke tests to generate temporary signing keys.
- [x] Update the GitHub release workflow to require `LOOPWIRE_RELEASE_PRIVATE_KEY`, sign artifacts, and smoke install
  with the matching public key.
- [x] Update secret setup helper and docs for release signing.

## Acceptance Criteria

1. Installer verifies `SHA256SUMS.sig` before trusting `SHA256SUMS`.
2. Installer rejects a tampered artifact even when the signed checksum manifest is valid.
3. Release artifact smoke verifies signed manifests for generated release directories.
4. Release workflow fails without the signing private key secret.
5. No private key material is committed.

## Remaining Phase Work

- Generate and commit the real project release public key before public release claims.
- Run the release workflow on GitHub with the real private key secret.
- Add AArch64 release signing coverage once an AArch64 build lane exists.
