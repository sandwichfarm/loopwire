# Phase 5 Plan: VM Compatibility Matrix

**Status:** Complete
**Requirements:** LINUX-01, QUAL-03

## Goal

Create a reproducible VM validation surface for representative Linux systems without requiring host mutation or nested
VM execution in normal CI.

## Tasks

- [x] Add `vm/targets.tsv` with representative distro, DE/WM, session, package-manager, and audio-server targets.
- [x] Add `scripts/vm-matrix.sh` with list, validate, doctor, plan, cloud-init rendering, and explicit dry-run launch.
- [x] Keep generated VM artifacts under ignored `.vm/`.
- [x] Add package scripts for VM list, plan, doctor, and validation.
- [x] Add a `VM Matrix` GitHub Actions workflow that validates metadata and shell syntax only.
- [x] Add VitePress docs for target coverage, launch policy, and evidence requirements.
- [x] Validate the script and docs through the project gates.

## Acceptance Criteria

1. Maintainers can inspect supported VM targets from source.
2. Maintainers can check whether the current host has the tools needed to run VMs.
3. Maintainers can render cloud-init/guest-command assets for a target.
4. CI catches malformed VM target metadata without trying to boot desktop VMs.
5. Docs state what evidence each VM run must capture.

## Remaining Phase Work

- Implement and smoke-test user-scoped start-on-boot.
- Harden installer behavior around release artifacts and checksums.
- Add AUR/Nix packaging smoke paths.
- Prove install from published artifacts before release claims.
