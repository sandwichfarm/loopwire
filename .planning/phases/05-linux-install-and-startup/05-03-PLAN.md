# Phase 5 Plan: Release Artifact and Package Smoke

**Status:** Complete
**Requirements:** LINUX-03, LINUX-04, QUAL-03

## Goal

Make the installer and package metadata testable against release-shaped artifacts before public artifacts exist.

## Tasks

- [x] Add `--base-url` to `scripts/install.sh` for local `file://` and alternate release mirrors.
- [x] Make installer checksum validation reject artifacts not listed in `SHA256SUMS`.
- [x] Add `scripts/verify-install.sh` that creates a local fake release artifact, installs it, runs it, and verifies bad
  checksum rejection.
- [x] Add AUR `PKGBUILD.in` metadata that references the same release artifact names as the installer.
- [x] Add Nix binary package template that references the same release artifact names as the installer.
- [x] Add `scripts/verify-packaging.sh` for static package metadata smoke.
- [x] Document package templates and publish boundaries.

## Acceptance Criteria

1. Installer release download/checksum behavior can be tested without network or published artifacts.
2. Bad release checksums are rejected.
3. Package templates reference `loopwire-linux-x86_64.tar.gz` and `loopwire-linux-aarch64.tar.gz`.
4. Docs do not claim AUR/Nix packages are published.
5. Validation gates include installer and packaging smoke commands.

## Remaining Phase Work

- Wire generated release checksums into package templates.
- Add actual release workflow artifacts.
- Add AppImage/deb/rpm artifact smoke from Tauri output.
- Run package builds from published artifacts before claiming install readiness.
