# Phase 5 Plan: AUR Local Package Smoke

**Status:** Complete
**Requirements:** LINUX-03 support path, QUAL-03

## Goal

Prove the AUR template can be rendered from generated release artifacts and built locally without publishing or
installing a package.

## Tasks

- [x] Add `scripts/render-aur-pkgbuild.sh` to render `packaging/aur/PKGBUILD.in` from local release artifacts.
- [x] Compute x86_64 and aarch64 checksums from generated tarballs.
- [x] Rewrite rendered `source_*` URLs to `file://` local artifacts for smoke tests.
- [x] Add `scripts/verify-aur-package.sh` to generate local artifacts, render the PKGBUILD, run `makepkg --nodeps`,
  and inspect the package archive.
- [x] Add `pnpm verify:aur`.
- [x] Document the local AUR smoke boundary.

## Acceptance Criteria

1. The AUR template renders without placeholder version or checksum values.
2. The rendered PKGBUILD can build in a temporary directory when `makepkg` is available.
3. The resulting package archive contains `usr/bin/loopwire`.
4. The smoke test does not install the package or submit anything to AUR.

## Remaining Phase Work

- Run AUR build smoke against real published release URLs after the first release.
- Add Nix package build smoke when `nix` is available in CI or a VM lane.
- Add signature verification before release artifacts are considered production-ready.
