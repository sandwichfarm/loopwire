**Status:** Complete
**Owner:** Codex

## Work

1. Add a deterministic writer/verifier for the complete release payload inventory.
2. Make Tauri bundle versions derive from the resolved release tag.
3. Restrict AArch64 staging to the verified tarball and AppImage surfaces.
4. Generate, checksum, sign, publish, download, and verify `release-assets.json` before and after evidence upload.
5. Add negative tests for mis-versioned, missing, extra, linked, and tampered assets.
6. Update release documentation and workflow contracts.
7. Run the complete local gate and hosted PR checks; do not create a public release.

## Acceptance Criteria

- The workflow creates or updates a GitHub Release only for an existing valid version tag.
- Exactly eight base payloads are required and classified; release evidence becomes the ninth payload.
- Every AppImage filename carries the release version and correct architecture.
- AArch64 GUI-only deb/RPM bundles cannot reach the release.
- The signed checksum manifest exactly covers `release-assets.json` and every listed payload.
- Remote download verification proves GitHub serves the same final inventory.
- Local and hosted validation pass and the issue-linked PR is open.
