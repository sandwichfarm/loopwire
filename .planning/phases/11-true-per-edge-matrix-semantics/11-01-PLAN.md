# Phase 11 Plan: Route-Control Semantics

**Status:** Complete
**Owner:** Codex
**Date:** 2026-07-03

## Goal

Make true per-edge route semantics explicit in the model and visible in backend diagnostics.

## Scope

- Add backend mixing semantics to audio-host capability reports.
- Mark PulseAudio compatibility as stream-level controls.
- Mark native PipeWire as link-only controls.
- Add desktop status for selected backend route-control behavior.
- Add a core regression for one source routed to multiple outputs with independent controls.
- Update docs and release notes.

## Out of Scope

- Implementing native PipeWire gain/mute processing.
- Implementing JACK graph-edge controls.
- Adding DSP nodes or per-edge processors.

## Validation

- Core tests and typecheck.
- Audio-host tests and typecheck.
- Desktop typecheck.
- Full repo validation after docs and state updates.
- Playwright visual smoke for the semantics status row.
