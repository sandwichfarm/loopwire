# Phase 8 Plan: Physical Monitor Device Binding

**Status:** Complete
**Owner:** Codex
**Date:** 2026-07-03

## Goal

Persist and apply monitor target sink names so monitor feeds can go to physical host outputs through the guarded pactl
adapter.

## Scope

- Add optional `deviceName` to core audio endpoints.
- Preserve `deviceName` through persistence and import/export.
- Add desktop editing for monitor host sink names.
- In the pactl adapter, create Loopwire monitor sinks only when no physical target is configured.
- Link output monitor sources to physical target sinks when `deviceName` is present.
- Verify physical target sink presence.
- Ensure unload removes Loopwire-owned loopbacks without unloading physical sinks.

## Out of Scope

- Enumerating physical sinks.
- Native PipeWire graph routing.
- Live host mutation during validation.
- Rich device picker UX.

## Validation

- Core tests and typecheck.
- Audio-host tests and typecheck.
- Desktop typecheck.
- Line-length checks.
- Full repo validation after docs and state updates.
