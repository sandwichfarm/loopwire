# Phase 10 Plan: Host Apply Consent and Runtime Wiring

**Status:** Complete
**Owner:** Codex
**Date:** 2026-07-03

## Goal

Wire desktop configuration runtime operations to selected host adapters behind explicit consent.

## Scope

- Add a browser-safe `@loopwire/audio-host/runtime` subpath.
- Add `@loopwire/audio-host` to the desktop workspace dependencies through the safe runtime subpath.
- Add a Tauri `run_audio_command` command bridge for allowlisted audio commands.
- Route selected backend operations to PipeWire or PulseAudio compatibility adapters.
- Keep preview mode non-mutating and live mode session-local.
- Fail closed outside Tauri or for disallowed commands.
- Update docs and planning state.

## Out of Scope

- Persisted live-apply consent across restarts.
- Live mutation during automated validation.
- JACK or ALSA live adapters.
- Native PipeWire virtual nodes or true per-edge gain/mute.

## Validation

- Desktop typecheck.
- Audio-host typecheck.
- Rust `cargo check`.
- Full repo validation after docs and state updates.
- Playwright visual smoke for the new host-apply control.
