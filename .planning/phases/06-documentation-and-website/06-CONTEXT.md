# Phase 6 Context: Documentation and Website

Loopwire needs public docs that are honest about support boundaries. The docs must help early users install from source,
understand backend readiness, start the app on boot, troubleshoot Linux audio issues, and follow release-note ceremony.

## Inputs

- Existing VitePress docs/site.
- VM target metadata in `vm/targets.tsv`.
- Installer, release, AUR, packaging, and autostart verification scripts.
- Current audio-host backend capability reports.

## Constraints

- Do not claim public release availability before signed artifacts exist.
- Do not claim full audio routing before monitor routing and graph-level mixing ship.
- Keep docs generated by VitePress.
- Keep documentation checks lightweight and dependency-free.
