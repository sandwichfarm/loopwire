# Phase 6 Plan: Documentation Contract and Release Notes

**Status:** Complete
**Owner:** Codex
**Date:** 2026-07-03

## Goal

Make the VitePress site cover install, startup, backend support, support matrix, troubleshooting, screenshots, release
process, and release notes with a small verification guard.

## Scope

- Add support matrix docs from the validated VM and backend contracts.
- Add troubleshooting docs for backend detection, stream matching, autostart, window chrome, and installer signatures.
- Add screenshot contract docs for keeping the homepage image aligned with the real app UI.
- Add release-note workflow docs and an unreleased notes page.
- Wire new pages into VitePress navigation.
- Add `pnpm verify:docs` and include it in `pnpm check`.

## Out of Scope

- Publishing the website.
- Creating public release artifacts.
- Booting VM targets.
- Adding new docs dependencies.

## Validation

- `pnpm verify:docs`
- `pnpm verify:scripts`
- `pnpm build:docs`
- Full repo validation after state updates.
